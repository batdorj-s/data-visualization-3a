## Бүтэц

```
.
├── docs/
│   ├── assignment/requirements.md      Бие даалтын шаардлага, үнэлгээний хураангуй
│   ├── research/                       Өгөгдлийн эх сурвалжийн судалгаа, хичээлийн зарчмууд
```

өгөгдөлд тулгуурлан гүйцэтгэлийг юу тодорхойлдгийг шинжилж, тоглолтын үр дүнг таамаглана.

- Дизайн: [docs/superpowers/specs/2026-11-12-mba-analysis-design.md](docs/superpowers/specs/2026-11-12-mba-analysis-design.md)
- Өгөгдлийн судалгаа: [docs/research/2026-11-12-data-sources.md](docs/research/2026-11-12-data-sources.md)
- Төслийн код: [mba_analysis/](mba_analysis/)
